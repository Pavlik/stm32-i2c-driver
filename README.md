# STM32 I2C Driver

Собственная реализация драйвера I2C для STM32G030.

## Цели проекта

- Изучение периферии I2C
- Работа через регистры CMSIS
- Работа через прерывания
- Поддержка нескольких устройств

## Структура

docs/      - документация и заметки

drivers/   - исходный код библиотеки

examples/  - примеры использования

I2C_lib/   - основной проект STM32CubeIDE
